# STAIRTAP: запуск боевой версии на Cloudflare

Всё живёт в **одном Worker** на Cloudflare: сайт, API, база D1 (аккаунты, проекты, подписки), публикация сайтов клиентов по ссылке `/s/…`.
Ключи (Gemini, платежи) лежат только в секретах Cloudflare и никогда не попадают в браузер и в код.

## Что понадобится
| Что | Зачем | Цена |
|---|---|---|
| Аккаунт Cloudflare | хостинг, база | бесплатно |
| **Workers Paid** (Cloudflare → Workers & Pages → Plans) | проверка пароля тяжелее лимита CPU бесплатного плана (10 мс), логин может падать с ошибкой 1102 | $5 в месяц |
| Ключ Gemini (aistudio.google.com/apikey) | ИИ | по факту использования |
| Lemon Squeezy | оплата картами со всего мира | комиссия с продаж |
| NOWPayments | оплата криптой (для тех, у кого карты не проходят) | комиссия с продаж |
| Resend (по желанию) | письмо «сбросить пароль»; нужен свой домен | бесплатный уровень |
| GitHub (для способа А) или Node.js 20+ (для способа Б) | деплой | бесплатно |

**Про ключ Gemini.** На бесплатном уровне Google может использовать запросы для улучшения своих продуктов и ставит жёсткие лимиты. Для платного продукта включите оплату в Google AI Studio (платный уровень) и поставьте бюджетное ограничение.

## Шаг 1. Деплой кода

### Способ А. Через GitHub (без командной строки)
1. Создайте на GitHub приватный репозиторий с названием **stairtap** и загрузите в него содержимое архива `stairtap-source.zip` (папка проекта целиком, без `node_modules`).
2. Cloudflare → **Workers & Pages → Create → Import a repository** → выберите репозиторий.
3. Имя Worker должно быть **stairtap** (оно прописано в `wrangler.jsonc`, при расхождении сборка упадёт).
4. Build command: `npm run build`. Deploy command: `npx wrangler deploy`. Нажмите Deploy.
5. База D1 `stairtap-db` создастся автоматически при первом деплое, таблицы создаст сам Worker при первом запросе.
6. После деплоя вы получите адрес `https://stairtap.<ваш-поддомен>.workers.dev`.

### Способ Б. С вашего компьютера
```bash
unzip stairtap-source.zip && cd stairtap
npm install
npx wrangler login
npm run deploy
```

Если база не создалась сама: Cloudflare → Storage & Databases → D1 → Create `stairtap-db`, скопируйте её ID в `wrangler.jsonc` в поле `"database_id"` и задеплойте снова.

## Шаг 2. Секреты и переменные
Cloudflare → Workers & Pages → **stairtap → Settings → Variables and Secrets → Add**. Для ключей выбирайте тип **Secret**.
После добавления нажмите **Deploy**.

| Имя | Что это |
|---|---|
| `GEMINI_API_KEY` | ключ Gemini. **Обязателен.** |
| `LEMON_API_KEY`, `LEMON_STORE_ID`, `LEMON_WEBHOOK_SECRET` | карты (см. шаг 4) |
| `LEMON_VARIANT_PRO_MONTH`, `LEMON_VARIANT_PRO_YEAR`, `LEMON_VARIANT_ULTRA_MONTH`, `LEMON_VARIANT_ULTRA_YEAR`, `LEMON_VARIANT_PACK_50`, `LEMON_VARIANT_PACK_200` | ID вариантов товаров в Lemon Squeezy |
| `NOWPAYMENTS_API_KEY`, `NOWPAYMENTS_IPN_SECRET` | крипта (см. шаг 5) |
| `RESEND_API_KEY`, `MAIL_FROM` | сброс пароля по почте (необязательно). Пример `MAIL_FROM`: `STAIRTAP <no-reply@ваш-домен.com>` |
| `PUBLIC_URL` | необязательно: адрес сайта, если нужен принудительный (например `https://stairtap.com`) |
| `GEMINI_MODEL_FAST`, `GEMINI_MODEL_PRO` | необязательно: смена моделей (по умолчанию `gemini-2.5-flash` и `gemini-2.5-pro`). Если Google отключит модель, впишите актуальную |
| `AI_GATEWAY_URL`, `CF_AIG_TOKEN` | необязательно: Cloudflare AI Gateway перед Gemini (логи, лимиты расходов) |

Кнопки оплаты показываются только для тех способов, которые вы настроили.

**Регион.** Google блокирует Gemini API для российских IP. В `wrangler.jsonc` задано `placement.region = gcp:europe-west1`, поэтому Worker выполняется в Европе, а не там, где сидит пользователь. Если в приложении появляется ошибка про регион, это значит, что Worker всё же вышел с неподдерживаемого адреса: подключите AI Gateway (`AI_GATEWAY_URL`) или поменяйте регион.

## Шаг 3. Проверка ИИ
1. Откройте адрес Worker, зарегистрируйтесь, введите идею, получите план.
2. В проекте откройте вкладку **Website → Generate website**, затем **Publish**: сайт откроется по ссылке `/s/…`, форма «лист ожидания» работает, записи видны в **Analytics**.
3. Ошибка «ИИ не настроен» значит, что нет секрета `GEMINI_API_KEY`. «Квота» значит, что исчерпан лимит ключа в Google. Подробности в Cloudflare → stairtap → **Logs**.

## Шаг 4. Оплата картами: Lemon Squeezy
Lemon Squeezy сам принимает платежи по всему миру и платит налоги за вас (merchant of record). Вам нужен аккаунт продавца и подтверждение личности/бизнеса. **Страны, в которые они отправляют выплаты, проверьте на их сайте до начала работы**: нужен банковский счёт или PayPal в поддерживаемой стране. Без этого карточный канал вам деньги не принесёт, тогда основной способ — крипта (шаг 5).

1. lemonsqueezy.com → создайте магазин (Store). Для начала включите **Test mode**.
2. Создайте товары и у каждого вариант (Variant):
   - Pro, подписка, ежемесячно **$29**;
   - Pro, подписка, ежегодно **$276**;
   - Founder, подписка, ежемесячно **$99**;
   - Founder, подписка, ежегодно **$948**;
   - пакет «+50 генераций», разовая покупка, **$7**;
   - пакет «+200 генераций», разовая покупка, **$24**.
   Цены можно менять, но тогда измените их и в `lib/plans.ts`. Там же лимиты тарифов.
3. Settings → API → создайте ключ → секрет `LEMON_API_KEY`. ID магазина → `LEMON_STORE_ID`. ID каждого варианта (в таблице Variants) → соответствующие `LEMON_VARIANT_*`.
4. Settings → **Webhooks** → Add: URL `https://ВАШ-АДРЕС/api/billing/webhook/lemon`, придумайте длинный секрет (его же в `LEMON_WEBHOOK_SECRET`), отметьте события: `order_created`, `subscription_created`, `subscription_updated`, `subscription_cancelled`, `subscription_expired`, `subscription_resumed`.
5. Проверьте покупку тестовой картой Lemon Squeezy (4242 4242 4242 4242), затем выключите Test mode.

Как это работает: вебхук выставляет тариф и дату окончания, отмена оставляет доступ до конца оплаченного периода, окончание подписки возвращает на Free, пакеты добавляют генерации навсегда. Повторная доставка вебхука безопасна.

## Шаг 5. Оплата криптой: NOWPayments
1. nowpayments.io → аккаунт → в Store Settings укажите кошелёк для получения денег (USDT и др.).
2. Store Settings → API key → секрет `NOWPAYMENTS_API_KEY`; IPN secret key → `NOWPAYMENTS_IPN_SECRET`.
3. Адрес для уведомлений указывать не нужно, приложение передаёт его само.
Крипта оплачивает один период (30 или 365 дней) без автопродления; повторная оплата продлевает дату.

## Шаг 6. Домен (по желанию)
Worker → Settings → **Domains & Routes → Add → Custom domain**. Домен должен быть в Cloudflare. Для писем о сбросе пароля подтвердите этот же домен в Resend.

## Шаг 7. Юридическое
Страница `/legal` содержит типовые условия, конфиденциальность и возвраты. Это шаблон: прочитайте, поправьте под себя (особенно правила возврата) и, по возможности, покажите юристу. Для Lemon Squeezy нужна живая страница с такими документами. Контактную почту на странице задаёт переменная сборки `NEXT_PUBLIC_CONTACT_EMAIL` (Settings → Build → Variables).

## Что проверено, а что нет
Проверено автотестами на эмуляторах (50+ проверок API и сквозной сценарий в браузере): регистрация, вход, лимиты и возврат генерации при сбое, смена тарифов по вебхукам (подпись, повтор, недоплата), крипто-вебхук, публикация сайтов, лист ожидания, сброс пароля, RU/EN, мобильная вёрстка.
**Не проверено с настоящими сервисами** (из тестовой среды их не видно): реальный Gemini, реальные Lemon Squeezy, NOWPayments, Resend и реальный Cloudflare. Поэтому пройдите шаги 3–5 в тестовом режиме до приёма денег. Качество сайтов, которые пишет Gemini, зависит от модели; кнопка «Change something» позволяет дорабатывать результат.

## Чего ещё нет
Вход через Google, двухфакторная защита, свой домен для опубликованных сайтов клиентов, автопродление крипто-подписок, админ-панель (смотреть пользователей можно через Cloudflare → D1 → stairtap-db → Console).

## Локальный запуск для разработки
```bash
npm install
cp .dev.vars.example .dev.vars   # впишите GEMINI_API_KEY
npm run build && npm run dev:api  # http://localhost:8787
```
